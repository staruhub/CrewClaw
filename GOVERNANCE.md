# Governance

CrewClaw is maintained by the `staruhub` repository maintainers.

## Decision Making

Routine changes are reviewed through pull requests. Maintainers evaluate changes against:

- the product boundary in `docs/prd_v0.20.md`;
- the Good Employee Standard;
- security and permission fail-closed behavior;
- test, evidence, migration, and rollback quality.

Substantial changes to architecture, protocol semantics, licensing, governance, or compatibility should include a design document or issue before implementation. TaskEvent changes must remain additive.

Maintainers resolve disagreements by seeking evidence and the smallest reversible decision that preserves user safety. The repository owner has final responsibility for releases, security response, and licensing.

## Maintainer Changes

Maintainer access is granted or removed by the repository owner based on sustained, trusted contribution. Changes to this governance document should be proposed through a pull request.
