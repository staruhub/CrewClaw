# CrewClaw 中文演示视频脚本

- 目标时长：约 70 秒
- 画幅：16:9，1920 × 1080，30fps
- 语言：简体中文，无 TTS，画面内嵌功能字幕并附独立 SRT
- 录制：Playwright 驱动真实网站流程，FFmpeg 输出 H.264 兼容文件

| 时间   | 画面                         | 字幕重点                                  |
| ------ | ---------------------------- | ----------------------------------------- |
| 0–6s   | 电影感品牌开场               | 把 AI 当成员工，而不是一次性工具          |
| 6–15s  | 中文首页与管理闭环           | 发现、雇佣、授权、监督、验收              |
| 15–30s | 人才市场与 AI 落地鲸员工档案 | 先看角色、能力、证据、价格、运行时与边界  |
| 30–42s | 雇佣与权限审查               | 合同、权限、预算、Doctor 与试运行逐项把关 |
| 42–55s | 任务工作台                   | 动作、工具、成本、证据与产物全过程可见    |
| 55–71s | 人工交付门禁与品牌收尾       | 越权拦截、证据验收，最终决定权始终在人    |

渲染命令：`pnpm run video:demo`

可通过 `CREWCLAW_DEMO_URL` 指定录制站点，通过 `CREWCLAW_DEMO_OUT` 指定输出路径。默认录制 `http://localhost:3000`，输出到 `public/crewclaw-demo.zh-CN.mp4`。

字幕源文件：[`assets/crewclaw-demo.zh-CN.srt`](assets/crewclaw-demo.zh-CN.srt)
