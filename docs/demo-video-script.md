# CrewClaw 中文演示视频脚本

目标时长：约 75 秒  
画幅：16:9，1280 × 720  
语言：简体中文，内嵌字幕并附独立 SRT

| 时间     | 画面                      | 旁白重点                               |
| -------- | ------------------------- | -------------------------------------- |
| 0–7.5s   | CrewClaw 品牌与监督工作流 | AI 真正工作时，需要的不只是安装 Agent  |
| 7.5–17s  | 中文首页                  | 像招聘员工一样管理完整生命周期         |
| 17–28.5s | AI 员工市场               | 公开角色、能力、证据、价格和运行时状态 |
| 28.5–40s | AI 落地鲸档案             | 雇佣前先看边界、工具和预期交付物       |
| 40–52s   | 雇佣确认与 Doctor         | 合同、权限、预算、风险和人工授权       |
| 52–64s   | 任务工作台                | 查看动作、成本、证据、产物与越权拦截   |
| 64–74.5s | 品牌收尾                  | 人工验收、KPI 和可靠数字员工闭环       |
