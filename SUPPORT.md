# CrewClaw Support

Use GitHub Issues for reproducible bugs and feature proposals:

<https://github.com/staruhub/CrewClaw/issues>

Before opening an issue:

- search existing issues;
- run `pnpm run crewclaw -- doctor` when the CLI is involved;
- include your operating system, Node.js, pnpm, Rust, CrewClaw revision, and relevant sanitized logs;
- remove credentials, personal data, local paths, and employee work artifacts.

Security vulnerabilities must follow `SECURITY.md`, not the public issue tracker.

The project is currently a release candidate and does not provide guaranteed response times or commercial support.
