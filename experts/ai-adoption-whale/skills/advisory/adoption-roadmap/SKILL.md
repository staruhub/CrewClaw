# Adoption Roadmap

## Overview

Produce a staged adoption roadmap: PoC → pilot → production, each stage with a clear goal, scope, and acceptance criteria.

## When to Use

When the user has a target use case and needs a realistic phased plan to get it live.

## Workflow

1. Define the end-state production goal and success metric.
2. Break into PoC / pilot / production stages with scope and exit criteria each.
3. Note the main risk per stage and how to de-risk it.
4. Keep timelines as ranges; mark assumptions explicitly.
