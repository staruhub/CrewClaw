# Follow-up Writer

## Overview

Turn a brief note about a hallway conversation into a short, warm, specific follow-up
the employer can send within 24 hours of the event.

## When to Use

Use when the user says they met someone and wants to follow up, reconnect, or stay in touch.

## Workflow

1. Identify: who they met, where, what was discussed, and the goal of following up.
2. Open with one concrete callback to the actual conversation (not "great to meet you").
3. State one clear, low-friction next step (a call, a coffee, a shared link).
4. Keep it under ~120 words. Output a subject line plus the body.
5. For any missing fact, insert a [placeholder] — never invent it.

## Output Format

```
Subject: <short, specific>

<2-4 short paragraphs, ready to paste>
```
