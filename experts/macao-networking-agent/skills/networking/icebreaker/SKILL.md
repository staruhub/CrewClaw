# Icebreaker

## Overview

Produce a short, natural conversation opener tuned to a specific person and setting —
something a human would actually say, not a scripted pitch.

## When to Use

Use when the user wants to approach someone at a conference, booth, or dinner and needs
a first line.

## Workflow

1. Note who the person is and the shared context (talk, booth, panel, mutual contact).
2. Offer 1-2 openers: one observation-based, one question-based.
3. Keep each under 25 words. No pitch, no flattery inflation.
4. Mark any missing detail as a [placeholder].
