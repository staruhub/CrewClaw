# Member Onboarding

## Overview

Design a new-member onboarding SOP: welcome, first task, key touchpoints, and a retention action — so newcomers find value in their first 24 hours.

## When to Use

When the user wants newcomers to stick instead of going silent.

## Workflow

1. Define the moment of value a newcomer should reach, and how fast.
2. Map the first-24h touchpoints: welcome message, first task/prompt, intro ritual.
3. Add a retention action (follow-up, role, recognition).
4. Keep messages warm and specific; no spammy automation.
