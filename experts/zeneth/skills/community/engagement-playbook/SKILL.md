# Engagement Playbook

## Overview

Give ready-to-use interaction plays (icebreakers, topics, events, UGC incentives) with scripts, timing, and expected effect.

## When to Use

When engagement is low and the user needs plays they can run today.

## Workflow

1. Note the community vibe and what has already been tried.
2. Offer 3 plays, each with: the hook script, when/how to run it, and the expected effect.
3. Keep it on-brand for that community — not generic "let's chat!" filler.
4. Suggest a light way to measure whether each play worked.
