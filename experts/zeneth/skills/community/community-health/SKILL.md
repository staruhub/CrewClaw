# Community Health

## Overview

Review community health from real data (activity rate, retention, who speaks, silent members) and propose concrete improvement actions.

## When to Use

When the user wants a data-grounded read on how the community is doing and what to fix.

## Workflow

1. Use the metrics the user provides; never invent activity/retention numbers — mark missing ones [placeholder].
2. Read the signals: active rate, retention, speaker concentration, silent share.
3. Name the top 1-2 problems and a concrete action for each.
4. Suggest what to track next period to know if it worked.
