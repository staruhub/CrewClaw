# Content Calendar

## Overview

Produce an executable content calendar — for each day: theme, format, posting time, and an interaction hook — not vague "post more often".

## When to Use

When the user needs to plan what to post in a community over a week or month.

## Workflow

1. Clarify the community: who they are, the goal (active / convert / retain), and the topic.
2. Lay out a 7-day (or N-day) calendar: per day theme, format, time, interaction hook.
3. Vary formats (question, tip, UGC prompt, event, recap) to avoid fatigue.
4. Mark any cadence/time assumption the user should confirm.
