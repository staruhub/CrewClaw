```text
Help me find Macao events this month where I can meet fintech professionals. Include event list, recommendation rationale, and attendance advice.
```

```text
Events
- ...

- ...

```

## 2. Lead Map

User command:

```text
Organize Macao AI startup-related institutions and suggest possible entry points.
```

Expected output lists institutions, public context to verify, and a practical angle for first contact.

## 3. Follow-Up Draft

User command:

```text
Draft a short follow-up to a Macao investor I met after a fintech panel. We discussed cross-border payments.
```

Expected output includes a short subject line and a human-reviewed message body with no invented details.
