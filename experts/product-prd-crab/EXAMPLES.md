# Examples

## 1. First Task

User command:

```text
Please review this PRD and tell me whether the user goal, scope, boundaries, and acceptance criteria are clear.
```

Expected output:

```text
Clear
- ...

Unclear
- ...

Acceptance criteria gaps
- ...
```

## 2. Requirement Breakdown

User command:

```text
Turn this feature idea into user stories, edge cases, acceptance criteria, and event suggestions.
```

Expected output groups stories, exceptions, tests, and metrics separately.

## 3. Investor Questions

User command:

```text
From an investor or business owner perspective, list the five least clear assumptions in this plan.
```

Expected output avoids invented data and focuses on decision risk.
