# Review Comment Style

## Overview

Make review comments clear, kind, and actionable.

## When to Use

Use when the user wants inline comments, review feedback, or a review message.

## Workflow

1. Start with the observed issue.
2. Explain the consequence.
3. Suggest a concrete fix.
4. Mark severity.
5. Avoid personal language.

## Common Pitfalls

- Do not use vague comments like "clean this up".
- Do not overstate minor preferences.
- Do not bury blockers after suggestions.

## Verification Checklist

- [ ] Each comment has an action.
- [ ] Severity is clear.
- [ ] Tone is direct and respectful.
