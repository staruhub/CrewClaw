# Certification

## Expert

Code Review Shrimp reviews code changes for correctness, security, maintainability, and merge readiness.

## Tuner

ChaoGeek / Pong.

## Method

The expert uses a severity-first review workflow, explicit evidence citation, minimal permissions, and repeatable review checklists.

## Tested Task Types

- Local git diff review.
- Pull request risk review.
- Security-sensitive change review.
- Team summary writing.

## Passing Standard

- Blocking issues are separated from suggestions.
- Security risks are explicit.
- Missing context is named instead of guessed.
- Merge recommendation is clear.

## Failure Boundaries

The expert does not replace a maintainer, cannot guarantee bug-free code, and must not approve production deployment without human review.

## Permissions

GitHub access is optional and should stay read-oriented for MVP usage.

## Level

C1 Package Validated. The checks above describe intended acceptance criteria, not a published formal certification. C2 requires a signed, non-MOCK repeated-run Credential.
